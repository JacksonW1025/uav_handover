## 首条held SP的有理数反例

A2固定首gap为相对t=0，初始网格t=−5 s，发布相位为−2 ms mod20 ms。因此初始读取的最近消息发于−5.002 s。源码 `p5_gap_windows` 将首gap安排在 `tr+3+1+1=tr+5`，其中tr是reposition结束时间。故该消息的真实profile时间为 **tr−.002 s**，仍在reposition的末尾，尚未进入hold。

runner `reposition` 的负方向末段源码公式为：

```
tau = tr - profile_time
s = -d + (a/2)*tau^2       (d>0)
v_ref = -a*tau
a = 1/2 m/s^2, tau = 1/500 s
```

将任意恒定origin平移到A2 hold端点−2.7 m，不改变速度或误差，得到：

```
实际源码参考相对hold端点的位移 Δr = 1/1000000 m
实际源码参考速度                  = -1/1000 m/s
A2 reference(-5002000)             = (-27/10 m, 0 m/s)
EP = 2^-21 + 10^-12 m
EV = 2^-23 + 10^-12 m/s
Δr - 2EP = 11858863/256000000000000 > 0
|v_ref| - 2EV = 1023755857327/1024000000000000 > 0
```

即使先允许实际源码值各有一个完整的原EP/EV偏差，剩余差异仍大于A2原包络。这里没有把普通double交叉检查误当形式化舍入证明：**严格反例来自有理数源码尾段公式及不等式**。另外隔离提取并执行未改动runner的三个纯函数，核对其普通浮点结果在1e−12内；再转binary32，位置差为 `19/20971520 m`，速度幅值为 `8589935/8589934592 m/s`，也分别严格超EP、EV。

计算选择合法负向reposition偏移−5.895 m、速度上限1 m/s、a=.5，origin平移3.195 m；尾段结果与d的具体值无关，只需末制动段包含2 ms。它是A2自己固定相位和源码公式的反例，**不是已执行飞行、不是所有时钟相位均不可能、不是倾角超限反例**。对机体/队列的两个不确定参数不作取点：参考误差与它们无关，故当前整个初始集合都不能用原参考包络套用该定理。

证据见 [counterexample.json](../data/p10-20261024-a2-review/audit/counterexample.json) 和 [隔离纯函数源码](../data/p10-20261024-a2-review/audit/pure-runner-formulas.json)。不通过改变发布相位、平移初始时刻、删除reposition/暖机、放宽w或目标包络修补此结果。现有5251个代理前缀的集合不等式本身不会修复初始参考前提为假。

## 已核源码关系与未闭合模拟关系分开

原A2逐项映射可继续作为查阅材料：有效native读取以本次hrt更新时间；超时严格`>200000 us`而非`>=`；捕获复制同源观测p/v；fresh接回原时间参数参考；RREC>0才允许START；恢复按gyro时钟积分；capture/profile/recovery transition先于sample-clock拒绝。因此不能把duplicate或early return一概当无事件跳过。

204 ms捕获、520 ms接回、11.704 s末捕获是**在手工初始化及固定read/publish时序下**正确的条件计算；它们不证明之前的held SP或队列初始化正确。runner的pump是callback调度，20 ms是最小发送间隔，并未证明所有实际调用精确周期。RREC0加初始恢复inactive确实能排除START；不能因此宣称覆盖了RREC>0、初始已有恢复、或全部恢复状态。完整字段枚举/分支表不等于完整模拟关系。

尚未建立：native状态到47维代理及capture辅助变量的抽象、真实暖机可达历史、每种允许读取/gyro/control顺序的逐步关系，以及严格w和输出插值接口。4 ms新代理的q指数插值仅补全输出，p/v梯形更新没有因此变成同一连续动力系统的精确积分。离散w不能限制任意采样间尖峰。详见 [关系审计](../data/p10-20261024-a2-review/audit/source-correspondence.json)。

未来若开展B，参数、初始队列/模块状态和明确时序可事前检查；日志可事后反驳时钟、event/order/topic假设，但不能用有限日志证明全域w或所有采样间输出界。初始化像、暖机传播和逐步模拟关系须先在A闭合，不能留到B用经验代替。
