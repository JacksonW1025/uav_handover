## 离散模型的精确扩维、函数和常数

每轴当前参考为 `(r_k,s_k)`，令 `e=p-r, d=v-s`，状态

```
x_k = [e_k,d_k,q_k,e_(k-1),d_(k-1),...,e_(k-11),d_(k-11)]  (25维)
u_k = -kp e_(k-11) - kv d_(k-11)
q_next = rho q_k + (1-rho) u_k
d_next = d_k + h/2 (q_k+q_next) + s_k-s_(k+1)
e_next = e_k + h d_k + h²/4 (q_k+q_next) + h s_k-(r_(k+1)-r_k)
history_next = [e_k,d_k,...,e_(k-10),d_(k-10)]
```

`h=1/125, rho=exp(-1/10)`，两轴 kp/kv 原样取 P9 模型 JSON 的十进制值，作为此代理的精确系数；并不声称拟合值等于真实系统参数。参考的 sample/hold、减速、跳变均进入
`b_k=[h s_k-Δr_k, -Δs_k, 0,...,0]`。所以 `x_next=A(rho)x+b+w`。`w`只允许作用于当前 e/d/q，历史必须精确移位；事件误差只作用于当前 e/d。时钟变化若改变 A/队列索引，不能静默塞进一个没有界的 w。

双轴 `X=(x_f,x_l)`，`V(X)=x_f'P_f x_f+x_l'P_l x_l`。两个 P 全部条目以整数/10¹⁰保存于 [certificate.json](../data/p10-20261024-a/construction/certificate.json)。它是有限历史的二次泛函，含 q 与所有历史交叉项，不是把 E 改名。

独立 [verify.py](../tools/p10/verify.py) 只用 Python 标准库 Fraction/整数：

- 用 exp(−.1) 的19阶奇数下界、20阶偶数上界，交错级数严格包围 rho；不依赖浮点 exp 正确舍入。
- 分数消元 Bareiss/Sylvester 逐一验证 `P > .5 I`；对称行和给 `P < 10000 I`。
- 在 rho 两端验证 `P-A'PA >= .5 I`，使用严格有理数 Gershgorin 裕度。因 A 对 rho 仿射且 P 正定，`A'PA`矩阵凸，端点不等式涵盖**整个区间**。不是扫描论证。
- 另证三个秩一矩阵不等式 `P > l_i l_i'/c_i`，`c_e=1/2000,c_d=21/10000,c_q=67/100`，所以 `|e|²≤c_e V, |d|²≤c_d V`，双轴 `||q||²≤.67 V`。

对无输入离散一步映射有差分耗散 `ΔV≤−.5||X||²`，因此 `||A X||_P≤β||X||_P`，可取 `β²=19999/20000`（或稍大的有理上界 β=39999/40000）。这是采样序列上的差分不等式，不是连续时间 `dV/dt`；参考和事件不被假装成耗散。

## 跳变、参考、误差及可计算约束

瞬时参考跳变 Δ=(Δr,Δs)，车辆 p/v/q连续，`x+=x−+JΔ`，J只在当前 e/d 写入 `−Δr,−Δs`，历史保持不动。因此

```
V+ - V− = 2 X−' P J Δ + Δ' J' P J Δ
sqrt(V+) <= sqrt(V−) + ||J Δ||_P
```

如捕获参考依赖车辆状态，必须对该依赖的完整预状态集合求界，不能只代入一个名义 Δ。对于已给全部参考值的序列，令名义中心 `Xhat`按上述 A/b推进；误差半径满足
`R_(k+1) ≤ β R_k + ||w_k||_P + ε_round,k + ε_ref,k`，在每个单独事件加 `||J δΔ||_P`。中心包含有符号采样参考输入，避免把高频 sample/hold 的抵消全丢成累积范数。

若只知原连续参考速度界 S、加速度界 Aref、相位偏差 |δt|≤ε，则参考的相位位置误差≤`S ε`（或局部展开含 `.5 Aref ε²`）、速度误差≤`Aref ε`；左右时刻分别包围后送入 J/P范数。若跨过捕获、恢复、退出等逻辑边，则必须枚举允许事件序列并检查所有前缀，不能仅用光滑斜率界。发布/读时钟不确定性、延迟索引变化同理；本交付**没有**为真实 runner 提供这些硬界。

## 倾角关系与采样间界

`q_att=-g R_z,xy/R_z,z` 且 `R_z,z>0` 时，纯几何恒等式 `theta=atan(||q_att||/g)`。在代理输出定义下，`V≤49 ⇒ ||q||²≤32.83 ⇒ theta≤30.296531°`。这个几何关系本身不需要竖直推力补偿；补偿假设是代理的 `v_dot=q` 动力学前提。

为补齐输出的采样间定义，明确给**离散代理的q输出**指定常指令一阶插值 `q(kh+s)=exp(-s/tau)q_k+(1-exp(-s/tau))u_k`。无离散扰动时它是 q_k 与 q_next 的凸组合，任意 s∈[0,h] 的范数不超过端点最大值，因此输出峰值界涵盖整个区间，而不只是251个采样点。**这仅是q输出补全，不是全状态连续流。** p/v端点仍按 P9 梯形公式，不声称它们和q插值共同精确满足连续 `p_dot=v,v_dot=q`；V域不变性也仅证明于离散采样序列，未证明连续 `V(X(t))` 的耗散或不变性。

条件扰动模型若在每tick末端才加当前状态残差，且 `||w||_P≤1e−4`，未加残差的 q 末端至多额外 `sqrt(.67)·1e−4`，同样给采样间界。对于真实系统，如果只在采样时有误差界 εq，尚须另有区间导数/插值误差硬界，例如 `||q_att(s)−q_proxy(s)||≤εq+L h` 才能加到范数上。没有这个前提，采样点安全不能推出实测倾角峰值安全。

高度不在 V 或输出界中；所有整体安全判定均 ABSTAIN。倾角代理证明、严格误差假设下的条件结论、真实 SITL 经验是三层不同对象，本轮第三层没有新样本。

4. **输出与任务**：若加入真实姿态误差和采样间包络，则倾角关系可转为条件上界。高度、最大落后/超前、追回、累计偏差和后续事件风险另需约束；仅靠减小接回跳步不能声称修复任务安全。C/CR已有权衡不变。
