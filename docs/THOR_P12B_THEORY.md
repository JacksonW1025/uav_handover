## 完整片段的条件映射

令H为世界向上高度，W=−dH/dt为向下速度，L=H_origin−H。对一个保持/接回/恢复物理片段、长度T：

`W_out = W_in + ∫a_down(s) ds + velocity_jumps`

`L_out = L_in + W_in T + ∫(T−s)a_down(s) ds + position/integration_defect`

`D_out = max(D_in, sup_prefix L)`。

速度jump对后续高度的影响必须按剩余时间加权；不能只加到末端W而遗漏之后的L。本轮精确有理数工具`margin_map.advance`把jump放在当前片段**末端**，下一段自然传播；片段内jump必须分段。时钟/交付范围决定实际模式词及T范围，native平台必须允许；未证明未来时长域时不能升级覆盖。

若`a_down≤a_bar`且给定几何/积分/接触误差预算ε，则B前的可检查充分条件为：

`D_B≤1 且 L_B + max_{0≤t≤T}[W_B t + a_bar t²/2] + ε ≤1`。

最大值必须检查两端与域内驻点；只检查终点会漏掉先下降后恢复的失败。AB的B前状态必须从A停流→真实capture→保持→resume→恢复组合得到；单事件安全本身不保证组合安全。下一事件间隔不足会保留W与历史/执行/cache偏离。该式的实际用途是把测试边界转换为所需的B前高度/垂速、整段推力和恢复时间域，而不是风险评分。

在单一常加速度片段，成对增量还有`|ΔW_out|≤|ΔW_in|+T E_a+E_jump`、`|ΔL_out|≤|ΔL_in|+T|ΔW_in|+T² E_a/2+E_geom/int`。E_a必须来自实际推力、姿态、执行及接触域，不能仅凭倾角峰值；多片段保留每段时序误差与相关capture项。神经/历史映射可逐模式接入，但本轮未获得覆盖其未来反馈域的有用闭合界。

## 从执行误差到垂向加速度

源码推力是有符号`k z_i|z_i|`，z_i按转向归一，k=8.54858e−6。若未来已知`|z_i−f_i|≤E_i`且`f_i−E_i≥0`，每项推力下界为`k(f_i−E_i)²`；否则用有符号单调函数的下界，不能把负推力截为零。若姿态锥θ≤θ_bar<90°、合力非负，可得垂直推力下界`cos(θ_bar) Σk(f_i−E_i)²`，再减去有来源的阻力/接触/其他力预算。反扭矩及力臂影响姿态，θ域也必须闭合。

物理world SDF g=9.8，与原M3/M4固定9.80665分开，模型未重调。x500源码质量2.0643076923076924kg，rotor惯性中心在转轴上；base到COM z约.001869131m。`gz sdf`本地URI完整解析显示merge frame另有.24m，因此truth命名model origin到COM为.241869131m，不能把truth H直接当COM。

`H_model=H_COM−e_z R r`，保留姿态相关几何项；θ≤45°时从任意域内起态到后态的该垂向差可用r(1−cos45°)覆盖，约.07084m。示例采用.075m总几何/积分预算，其中积分缺陷约.004m只是**未验证假设**。最初URI解析exit0但部分失败的文件保留且不用作几何依据；实际依据是`resolved-model-local-uri.sdf`。

独立示例：B前剩余高度.5m、向下速度.2m/s，整个保持+接回+恢复T=1.16s，θ≤45°、E_j≤1rad/s、其他下向力预算.6451424N、总几何/积分.075m，则充分条件为各filter全段下界约**916.901rad/s**，低于配置上限1000。这里阻力预算由四rotor、Ω≤1000、相对空气速度≤2m/s及源码系数8.06428e−5构造。不是用正式最大值拟合；没有证明实际闭环始终满足这些域，也没有证明神经能实现该filter下界。这个代数可行的整段约束不能作为已验证修复准入。

固定RTDEC2修复的捕获输入误差在准备中接近零、全保持段未裁剪，是实测结果，不等于全程安全充分条件。若要推导完整修复参数范围，必须联合检查减速参考整个hold、resume跳变、执行filter/joint以及恢复至B前的上述域。本轮未证明一个覆盖全部实际未来的RTDEC区间。
