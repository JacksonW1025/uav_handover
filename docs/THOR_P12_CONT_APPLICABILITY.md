# 实验可比性与理论适用性独立规范

正式实验门由冻结的`experimental-protocol.json`及`frozen-experimental-protocol.json`规定，完整理论未证明不单独阻止运行。本轮确已启动27项，最终因新冻结初始化相位审计错误停止，未因动作绝对增量界2而停止。

实验必须一致的是任务参考与epoch规则、RINI4/RTGT0/RTDEC2/RREC0、预事件修复抑制和同一对照内分配的读取门。LP/att阶段、真实初始p/v/SO3/h/previous/mean、filter/joint/消费命令和sample/native/host差异原样记录。连续诊断限为p .10m、v .15m/s、SO3 2.5°、h L2 .5、previous/mean分量 .1、filter分量30rad/s；它们不是理论集合证书，不用于挑出好看的处理结果。缓存类别一致性、连续诊断及最小有意义效果5°/.2m/.2m分别列出。自然重复方差只用于判断辨识能力，不自动放宽限值。

原子全状态分叉不可用，故采用冻结的随机分块；实际达到的相位、是否存活到B和处理后峰值不用于筛选组。缺失NORMAL不替换，完整六臂组与仅满足某个预声明对照所需的可用臂分别报告。可用对照保留初态差异，不能转称严格同初态因果证明。F4只有一个边界块，不能把两门或多个模型当作跨种子重复；未完成的F2重复不生成计划中的n3推断。

理论适用条件另列：

- GRU实际权重/模式固定，h在源不变域内；逐分量H/X的有理系数证明是real映射关系，浮点运行误差/全反馈域另查。
- capture初值必须来自同一缓存p/v/q；capture不重置神经/动作/执行历史。不同捕获时刻需另含时间差和模式流动，不能独立自由选目标初值。
- 减速参考的整段增量界、捕获瞬时alpha条件、分支切换滤波界具有明确源码依据；整段不裁剪的a区间还要求真实加速度和缓存误差域，不能从有限记录最大值宣布这些域已证。
- 已消费命令到filter的初值与动态可直接核验；到真实joint的未来关系还缺SERVO约束冲量/求解残差域。body/EKF/cache/排队连接继续缺失，绝对世界高度安全余量不能仅用估计器NED代理代替。
- native时间允许跳进、平台与追赶；真实未来调度词仅用于评分，不能注入自主预测。名义点预测及有限情景包络不是已证覆盖。

因此所有经验组的完整闭环集合准入均NOT_PROVEN；A4仍NOT_PROVEN_EXCLUDED。实验效果、模型预测误差、局部源码约束、完整安全证书及CI分别报告，不以任何一个的通过替代另一个。
