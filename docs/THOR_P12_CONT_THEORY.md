# P12续轮：整个保持段的修复约束与尚未闭合的后段

本附录是离线解析工作，不改变68dfb73b冻结的任何实验参数/划分。只使用源码关系与事前给定符号域，未用正式结果拟合加速度或误差界。M2/M3基线和M4数值参数保持冻结。完整反馈储能与A4排除仍未证明。

## 不同捕获时间下的相关参考界

沿用旧P12已证明的速度径向减速 `b_a(v,t)=prox_{at||.||}(v)`，对v非扩张，且对时间的Lipschitz常数为a。两条轨迹的捕获时刻c1/c2不同，分别从它们自己的实际读取缓存捕获p1/v1、p2/v2；这些初值必须来自同一闭环初始集合的演化，不能任意独立选球。

在**两者均已捕获且均尚未resume**的共同绝对时间段，若 elapsed<=T、|vi|<=L、|c1−c2|<=E_c，则

`E_s(t)<=E_v_capture+a E_c`,
`E_r(t)<=E_p_capture+T E_v_capture+L E_c`。

第一式用对v的非扩张和对时间的a界；第二式用积分参考对初速的T界和速度幅值L的时间积分界。真实实现还需旧文档的浮点转换预算。这是允许不同停止时刻的参考段关系；一条已capture而另一条仍fresh、或者任一已经resume时必须另列模式，不能套此式把不同模式抹平。网络/执行/机体历史不在capture时清零。

## 保持全段不裁剪的条件性修复参数区间

考虑alpha=1、a>0的同源水平速度捕获。设整个真实保持段长不超过T，真实水平加速度满足||a_body,H||<=A。设真实机体与读取缓存的位置误差在捕获及当前时刻合计<=eps_p，速度误差合计<=eps_v，捕获时速度缓存误差<=eps_v0。目标严格用源码连续减速公式，非自由独立初值。

从速度积分和参考减速度幅值<=a，整个0<=tau<=T有

`||v_read,H−s_H|| <= (A+a)tau+eps_v`,
`||p_read,H−r_H|| <= .5(A+a)tau²+tau eps_v0+eps_p`。

水平yaw旋转为等距映射，2范数界足以控制每个水平输入轴。于是保持全段水平速度输入不越1m/s、位置输入不越.5m的充分条件是

`0<a<=min((1−eps_v)/T−A, 2(.5−eps_p−T eps_v0)/T²−A)`。

右端必须为正，边界浮点/观测误差需另留预算。它给出**整个capture至resume保持段**的可计算参数约束，比“捕获瞬时速度误差为0”更强，但仍是有明确加速度/cache域前提的子系统结论。

示例仅为事前假设域：T=.16s、A=3m/s²、eps_v=.02m/s、eps_v0=.01m/s、eps_p=.02m时，速度条件给a<=3.125m/s²，位置条件给a<=34.375m/s²，固定a=2满足两者，保持末速度误差界.82m/s、位置界.0856m。这里**没有证明实际允许未来域满足A=3及这些cache误差界**，示例不是实验准入或整飞行安全证书，也没有据正式结果反选A。

反例边界：若只知道捕获瞬时误差0，而允许保持段身体加速度沿原速度方向A=8、参考反向减速a=2，初速1.8m/s，则速度差为10tau，在tau>.1s后裁剪，即使capture瞬间为0。该构造是满足所给运动学加速度类的反例，不是已证明可由真实闭环实现的飞行反例；它说明瞬时局部修复条件不能直接替代全段条件。

## 垂向和完整接回后段

修复不匹配垂向速度：target垂向速度仍0，绝对世界高度不重置。若初始真实垂速幅值<=Vz、真实垂向加速度幅值<=Az，则保持段的世界高度损失最多Vz*tau+.5Az*tau²（再纳入初始高度/坐标/采样误差）。输入z和世界高度约束分别检查，不能从水平不裁剪推断高度安全。

resume跳回原绝对任务表，接回瞬间的新相对误差必须由整段实际机体与已知任务目标计算，不承接“capture误差0”。h/previous/mean/count、filter/joint/pending command均继续。接回后恢复至任务末段需把网络多模式增量、滤波关系及绝对安全余量联成反馈；本轮不删除此段，也没有证明其可被上述保持段区间覆盖。

第一个未闭合物理连接仍是执行求解器：SERVO约束条件下 `e_j(next)=slowdown*(eta−c D lambda)`，缺允许未来域的冲量与求解等式残差界，随后还缺body/EKF/cache反馈域。因此A、Az、cache误差不能仅由约9e-8观测残差、局部Jacobian或一个风险分数获得认证。完整储能不通过不单独阻止预冻结机制实验；这些实验帮助定位实际响应/误差域，有限记录不能升级为硬覆盖。
