# P12 独立评分修订：截断、失败见证及分母

本修订只纠正离线评分，不新增SITL、不生成新预测、不拟合参数，也不回写P11或原P12结果。原交付提交`d917f2d85855e869e47bdf9fa044d228b8514c25`及`data/p12-20261026-analysis/*-score/`、`delivery-v1/`保留。当前评分以`tools/p12/score.py`（schema `p12-scoring-2`）、`data/p12-20261026-score-review/`和`delivery-v2/`为准。

## 原缺口及纠正

旧P11评分器被P12复用。全程倾角标签对停止且无`stop.angle_deg`的预测给UNKNOWN，但任务标签只对`NUMERICAL_UNCERTAIN`停止覆盖UNKNOWN；一般出域停止可能仍为AGREEMENT。旧倾角判失败还依赖停止元数据，遗漏了实际预测trace中已经出现的>45°样本。因此原7条`uncorrelated_capture`的任务AGREEMENT不能支持完整任务一致。

实际核对发现，这7条预测均在截断前有有限、有效的倾角越界见证（约45.118–45.538°），而对应实测任务完整且安全。正确标签是**倾角FALSE_ALARM、任务FALSE_ALARM、高度UNKNOWN_PREDICTION_TRUNCATED**。不能机械地把所有停止都改为UNKNOWN；也不能从安全前缀推出整程成功。

修正版统一三个分项的三值状态：

- FAILURE：有效预测/观测前缀内已见严格`tilt>45°`或`altitude_loss>1m`；task是两个分项的OR，因此一个已知失败足以确定task失败。
- SUCCESS：覆盖相应完整比较区间，且未见该分项失败。未建模的高度不能判成功。
- UNKNOWN：安全但不完整的前缀、数值不确定尾段、缺少起点/窗口覆盖或未建模状态。UNKNOWN不计AGREEMENT，也不作为完整的DANGER_MISS/FALSE_ALARM。

分类只比较双方已知状态；完整安全实测与有效预测前缀的失败见证可判FALSE_ALARM，但其完整轨迹/峰值误差仍不可计算。双方失败前缀可判失败标签AGREEMENT，必须另标“失败见证一致”，不能称完整轨迹一致。数值停止行本身不供失败见证，之前的有效见证保留。任何种类的安全提前停止，包括元数据无stop但轨迹明显短缺，均保持UNKNOWN。

窗口使用自己的覆盖和停止位置，不继承全程的截断布尔值；停止发生在某窗口以后，不使该已覆盖窗口变成删失。未到达的实际窗口仍为NOT_REACHED。高度窗口使用原共同任务起点，不逐事件重置损高基线。原严格安全阈值不变，原完整预测4.1ms/实际事件窗口4ms采样容差保留；未放宽标准。

7条已见开发成功记录×6模型/消融＝42组预测—实测对，不是42次独立飞行，也不是正式留出。全部预测数组、输入测量、原评分、P11评分器与P11机器结论/停批诊断，以及启动账本共74项哈希在重评分前后完全一致。

旧全程倾角为35 AGREEMENT＋7 UNKNOWN，旧任务为42 AGREEMENT。修正后，7条去相关捕获消融的倾角/任务均为误报；该消融的完整峰值误差分母为0、完整轨迹RMSE分母为0，仍可报告7条共同前缀RMSE。其余5种模型各有7条完整开发对，完整峰值误差总分母35；共同前缀误差总分母42。分类分母和完整轨迹分母不得混用。

168个预定事件窗口的倾角/任务为154安全一致＋14误报；高度为154安全一致＋14UNKNOWN。原事件倾角标签本已利用trace峰值，这些标签未改变；14个早期已完整覆盖窗口的censored标志由true纠正为false。嵌套窗口与同一记录上的模型对照高度相关，不当作IID样本。

位置/速度/倾角逐点误差及完整/共同前缀峰值误差全部数值不变。7条`no_history`高度损失原包含未观测预测延续，现在只计共同实测任务区间，最大数值差约0.00013663m，未改变高度失败标签。原数值、范围变化和全部变更逐条登记在`correction.json`、`denominators.json`中。

M3七条开发成功案例的峰值误差仍约0.051–1.613°；这不泛化危险预测，修正也没有增加失败实测或新留出。消融是模型方程比较，不是实际飞行因果干预，完整证书状态未因此改变。
