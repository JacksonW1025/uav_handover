# P12 可组合子关系与完整闭环储能的具体障碍

这里不是评分器。交付真实源码对应的成对跳变、完整持有段参考增量界、执行滤波有限时域界及可计算捕获修复条件；完整机体闭环安全和修复后段准入仍须独立通过。所有结论有作用域，不把重放或经验情景包络当硬界。

## 相关捕获及整个减速参考段

同一实际模式/调用阶段，两条轨迹的捕获缓存为 `(p,v,q)` 和 `(p~,v~,q~)`，目标复制同一p及yaw。水平速度捕获系数alpha（P12实际只有0或1）时，捕获后的策略位置输入误差为0，水平速度输入为`(1-alpha)*v_H`；成对关系是

`delta(p-r)=0`, `delta(v_H-s_H)=(1-alpha)*delta v_H`。

h、previous、mean、count在capture跳变时均不变；旋转输入仍由q及同源捕获yaw相关决定，垂向速度输入仍为v_z。不能把目标和机体误差当独立球，不能由水平零误差推断姿态、世界高度或后段安全。不同capture时刻/不同guard模式不能直接套同相位跳变矩阵，必须另传播两者间的真实流动与缓存更新。

设固定减速度a>0，速度参考为`b_a(v,t)=(1-a*t/||v||)_+ v`（v0时为0）。它是凸函数`a*t*||.||_2`的prox：由最优性`v-b in a*t*partial||b||`及次梯度单调性，

`||b(v,t)-b(w,t)||² <= <b(v,t)-b(w,t), v-w>`，

所以`||delta b||<=||delta v||`。目标位移`D_a(v,t)=integral_0^t b_a(v,s)ds`与TargetProfile闭式公式一致，由积分三角不等式对整个`0<=t<=T`有

`||delta r(t)|| <= ||delta p_capture|| + T*||delta v_capture||`,
`||delta s(t)|| <= ||delta v_capture||`。

这是整段目标持有/减速参考的可组合增量界，包括两条参考停止时间不同的情况，不要求共同停在同一公式分支。它不覆盖resume跳回绝对任务目标后的机体响应；下一capture重新使用当时相关p/v，不把第一次初值永久沿用。双精度求值后float32输出需加cast项。限定|p_capture|<16m、|v_H|<4m/s、a=2、T任意，参考位移<=4m，取每条位置2e-6m、速度5e-7m/s覆盖该范围的输出float32转换（基础real公式界与完整硬件舍入认证分开；开发连续重放仅是实现一致性证据）。成对界应加两条各自的cast预算。

实际用途之一是配对可分辨性：若待比较事件段目标位移差预算为eta_r，预事件capture误差须满足`E_p+T*E_v+2*eps_r<=eta_r`。这给出与时域相关的可计算配对条件，不是固定宽松阈值。它只约束参考，不足以证明两条机体输出差可忽略；故本轮不能据此把P11门限升级为完整严格配对域。

捕获瞬间每个目标yaw水平轴速度输入限制1m/s。若整个允许集合有`|v_i|<=L`，则

`(1-alpha)*L+eps_v<=1`，即`alpha>=max(0,1-(1-eps_v)/L)`。

这是一项实质修复参数约束，来源是完整初始集合，不是评分阈值。P12固定alpha=1、a=2，在实际首次activation仍alpha0；实验捕获后使用已存在的连续减速源码。此不等式只保证捕获瞬时不因水平速度跳变而裁剪，**不能保证整个后段安全**。整段准入还必须传播下面的执行/网络/机体关系及所有绝对安全余量；本轮没有通过该更强关卡。

## 加减速切换下的实际执行滤波

真实Gazebo内部状态f，已消费命令u，步长dt，

`F(f,u)=rho_up*f+(1-rho_up)*u`（u>f），否则rho_down，
`rho_up=exp(-dt/.0125)`, `rho_down=exp(-dt/.025)`。

两分支在u=f连续；沿两点间线段，几乎处处的导数为`(rho,1-rho)`，rho位于两个端点之间。故无论两条轨迹是否跨越不同分支，对于`|delta f|<=E, |delta u|<=U`，

`E_next <= max(rho_up*E+(1-rho_up)*U, rho_down*E+(1-rho_down)*U)`。

这是全局、同一dt的分段增量关系，允许单环节放大，不依赖采样Jacobian。在相同未来命令序列U0时，完整时域

`E(T)<=exp(-T/.025)*E0`。

例如E0=1000rad/s、T=.2s后<=.335463rad/s；它界的是同命令下初始滤波记忆的消失，不把末命令稳态假设变成实测初值，也不包含闭环未来命令差。U随步变化时逐次用上面的max映射，或联入储能/可达集合。P12直接记录filterBefore/After及完整命令，连续重放只初始化首行一次；观测解决的是这一状态的实际初值接口，不等于解决真实关节/力矩误差。

源码推力由本步实际关节转速乘slowdown得到w，`T=direction*sign(w)*k*w²`。在`|w|,|w~|<=Omega`，有`|delta T|<=2*k*Omega*|delta w|`。因此必须把关节跟踪残差`e_j=|w|-f_before`作为有状态误差纳入连接，不能将滤波差直接代替实际转速差；力矩还涉及姿态、气动和求解器。该残差本轮直接观察，但未来确定性演化界尚未证明。

## 从实际权重导出的模式增量关系

权重来自原冻结policy.tar，不训练。GRU源码顺序r,z,n：`r=sig(Wir e+Whr h+br)`, `z=sig(Wiz e+Whz h+bz)`, `n=tanh(Win e+bin+r*(Whn h+bhn))`, `h*=(1-z)n+zh`，`e=ReLU(W0 x+b0)`；输出`a=clip(W2 h*+b2)`。若h在[-1,1]^16，凸更新保持该域。sig全局Lipschitz1/4、tanh/ReLU/clip非扩张。

令`B_i=sum_j|Whn_ij|+|bhn_i|`，逐分量误差向量满足

`delta_abs h* <= H delta_abs h + X delta_abs x`，其中
`H=I+|Whn|+diag(B)|Whr|/4+|Whz|/2`，
`X=(|Win|+diag(B)|Wir|/4+|Wiz|/2)|W0|`。

证明依次用门差的1/4界、`|Whn h+bhn|<=B`、`|h-n|<=2`及乘积差展开。native模式提交该h*，intermediate保留h但其输出仍依h*；输出界为`min(2,|W2|(H E_h+X E_x))`。mean更新是`delta mu'<=n/(n+1)*delta mu+1/(n+1)*delta previous`，仅在计数相同的成对模式下可直接套；不同计数要分离模式。不能抹掉每个intermediate输出对previous和下一均值的作用。

`tools/p12/theory.py`以精确有理数处理存储的binary32 dyadic权重，输出可复算H/X/输出矩阵及hash；这里的精确算术认证是权重系数和real数学不等式，不包括所有运行库/浮点实现误差。无有限差分Jacobian替代全域证明。所得h∞增益约10.9752，x到h约57.5965，输出增益约35.6294/160.8493。两个initial/input逐分量误差各.001、按native/intermediate交替、已知外生输入误差固定的示例，第4次输出界到达2（整个动作箱），失去区分能力。不是GRU必须孤立收缩的论证，也不是完整反馈LMI不可行的证明；加权完整闭环关系仍可能有用。这里展示了具体不等式、模式和最早失去用途的位置。

## 时钟、A4反例和完整闭环障碍

时序词包含真实sample、native及host区间。守卫用native而提交用sample/真实计数。P11第70条native 8ms跳进再平台被P12诊断器和状态机接纳；它不能被当成丢样。给定完整合法调度词，模式可顺序计算；未来词只有在事前调度装置或确定界成立时才能作为准入前提。真实未来词只供已知输入核验，不能偷进自主预测。

完整混合增量储能需要在扩展状态上证明每个实际模式`V+<=a_mode V+input_terms`及成对capture/resume跳变，然后在每个前缀用`tilt_nominal+SO3_error<45deg`、世界高度余量及跟踪误差恢复绝对约束。P12已将实际滤波初态从未知稳态近似变为直接读数，但**最早缺失的连接仍在命令选择后的第一个物理/估计器更新**：关节/力矩/机体及缓存/估计误差的因果有状态演化，没有覆盖未来允许域的硬界；而全域网络增益直接连接也过宽。没有据此宣告整个方法只能是风险分数。

A4误差球反例在p/v/q物理支撑任意每步创新22次。P12的滤波子约束没有给出从该p/v/q创新到真实执行/估计误差的必要关系，所以尚不能证明反例违反P12完整可实现接口。结论保留NOT_PROVEN_EXCLUDED，A4 NOT_PASSED不变。简单禁掉大创新或只保留有利记录会破坏覆盖要求，不能采用。

P12候选M3显式双时钟/真实调用计数/缓存/相关capture/history/直接滤波初态；机体仍用冻结P11 M2的经验系数。隔离入口只读初值、源码任务和声明调度，四消融在相同案例/参数上比较。它们改变预测方程，不是完整飞行的因果干预，不改变真实证书状态（完整证书均未建立）。有限预置时钟/初值情景只给条件经验包络，不能冒充区间已证覆盖。
