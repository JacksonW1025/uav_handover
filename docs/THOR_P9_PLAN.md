新连续水平代理在**目标偏航 FLU 系**保留 p、v、q 及延迟历史：

```
p_dot = v
v_dot = q
q_dot = (-q - kp*clip(p-r, ±0.5 m)[t-delay]
                  - kv*clip(v-vr, ±1 m/s)[t-delay]) / tau
tilt = atan(norm(q)/g)
```

辨识 q=-g*R_body_z_xy/R_body_z_z，假设竖直推力补偿；这不是测得的真实水平加速度。
按目标偏航旋转后，两轴分别辨识正增益。延迟 0–160 ms（步长 8 ms）、tau
40/80/120/160/240/320 ms 的固定网格，每条飞行等权；不用样本量把长飞行加权放大。

## 失配账本与理论边界

令 e=p-r、dv=v-vr，Phi 是 kp*clip(e,±0.5) 的逐轴积分（饱和后线性增长，
不丢掉未截断位置积累），E=Phi(e)+|dv|²/2。在连续段：

```
dE/dt = -sum(kv*clip(dv)*dv)
        + dv dot (q + kp*clip(e) + kv*clip(dv))
        - dv dot target_acceleration
        + kp*clip(e) dot (vr - r_dot)
```

事件处机体 p/v/q 连续，目标重置导致 Delta E，可在查询前按模型计算，并保存每个捕获与接回的
Delta E、正注入累计、p/v/q和目标向量、必要的截断输入延迟队列。
理想连续目标满足r_dot=vr时末项为0；采样保持的位置与速度前馈一般不满足这个关系，
因此必须保留运输失配项，不能用连续参考的等式冒充完整采样系统证明。
数值输出的正值计数仅是“名义耗散＋延迟残差”代理，未含目标加速度和运输残差，不叫完整E导数。
理想无延迟、瞬时 q、匀速连续目标下第一项非正；
实际存在延迟残差及目标加速度项，例如 e=0、dv 与 q 同向时 E_dot>0。
增加 tau*|q|²/2 也尚没有覆盖延迟历史和模型误差的负定证明。
**当前候选不是 Lyapunov 证书**；集合之外不判必败，二分也不称理论贡献。
本轮理论结构只为搜索划分局部区段、候选优先级及修复的任务代价约束提供可检验启发式。
若结构无效，报告负结果，仍完成预算内 B/D。
