# 四类交接问题

交接时依次记录请求、控制器激活、神经命令首次发布、四电机首次应用，以及新控制器首次读入有效参考。前四个事件回答控制权走到了哪里，最后一个事件回答接手方从何时开始追踪新轨迹。

| 分类 | 对照操作 | 用于验证的信号 |
| --- | --- | --- |
| [T1](T1.md) 接管后安全余量不足 | 对同一紧弯参考调整控制器及接管时间 | 原生姿态、参考速度、位置与速度误差、后段四电机身份 |
| [T2](T2.md) 控制器历史状态接续错误 | 固定参考并读取经典上一动作，改变 GRU 入口状态 | 原生策略输入、GRU 门与下一状态、四路命令、闭环高度 |
| [T3](T3.md) Setpoint 参考接续异常 | 调整外部参考首次恢复时刻 | 临时目标、首条接受参考、四电机接管时刻、实际速度和倾角 |
| [T4](T4.md) 控制权实际交付异常 | 改变下游暂存解除时刻 | 发布者与样本时间戳、relay 转发、四电机物理步采用 |

T1 的 35° 是紧弯实验的倾角预算。T1 和 T3 原始运行记录中的 45° 是实验保护门限；离线表格按原生采样窗报告观测峰值。时间以各页标明的轨迹相位或原生事件为零点。

[复现指南](REPRODUCTION.md)列出发布样本和原始日志的入口。四类的原始定义与证据来源固定在 [2026-11-16 证据快照](https://github.com/JacksonW1025/uav_handover/tree/141a2b31becee1a909e0d76f552b0724eb315f99)。
