## 本轮最直接的结果

- **T1：同一紧弯参考，两个神经臂在同一后段达到约 43°，经典约 25.90°。** 提前 3.3 s 完成交接仍出现相近峰值。原生记录把问题定位在后段运动状态与神经闭环响应，而非只看切入瞬间。
- **T2：同一物理/参考输入，仅改变历史，首轮输出就明显不同。** 同时接好 GRU 与真实上一动作，最大单电机命令变化的五帧均值为 0.0132；两项清零为 0.2191。125 个连续插值点进一步展示两种历史的相容关系。
- **T3：首条发送及实际采用的目标逐值相同，仅延长首次等待，仍能放大瞬态。** 两臂电机接管至有效参考间隔为 16/80 ms，倾角峰值为 2.89°/7.28°，失高为 3.49/4.89 cm。这里观察的是轻缓场景中的瞬态放大，没有保护越界。
- **T4：把“谁发布”与“哪条样本真正应用”分别核对。** 发布门控的 16 组合组件测试通过；原始四电机数据重算确认受控暂存使首次神经应用由 +4 ms 变成 +8 ms，首条神经样本被覆盖，通常应用步仍消费经典样本。
