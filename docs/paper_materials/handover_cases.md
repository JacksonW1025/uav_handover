# 控制交接案例与论文引言素材

核对日期：2026-11-12。以下为中文概述，不是原文引述。页码如无特别说明均指 PDF 阅读器从 1 开始的页码。

## 1. 首选案例：Malloy T005 进入 AUTO 后失控

**事件：** 2024-04-02，英国 White Waltham Airfield。**来源：** AAIB Bulletin 2/2025，AAIB-29959；网页发布于 2025-02-13。属于 AAIB correspondence investigation，技术发现部分引用运营方调查。

**报告事实：** 团队先短飞验证 STAB、ALT HOLD、LOITER，重新布置并再次起飞后选择 AUTO；飞机爬升、左偏并撞上两架无人停放的通航飞机。调查指出飞行模型不适配该机推重比、推力指令过大、反馈调参不足。AUTO 还忽略主控制器的飞行终止指令；备用控制器最终成功触发终止。

**可用作研究动机的推论：** 验证其他模式正常，并不能覆盖新模式激活后控制输出与安全处置的交互。进入条件、控制行为及应急接管应联合测试。

**不能据此声称：** AUTO 使用了神经控制器；已排除模型/调参问题而证明纯切换逻辑致险；两套控制器分别都已充分证明安全。报告提及视觉跟踪功能，但未说明是否使用神经网络。

**复核入口：** [官方调查页](https://www.gov.uk/aaib-reports/aaib-investigation-to-malloy-aeronautics-t005-uas-registration-n-slash-a)；[PDF](https://assets.publishing.service.gov.uk/media/67a0a96ee04de3153316a3ca/Malloy_Aeronautics_T005_UAS_reg_n-a_02-25.pdf)。PDF pp.1–2（飞行过程）、p.4（记录与 FTS）、p.5（Technical findings）、pp.7–8（Analysis/Conclusion）；纸面页码 21–28。引用键：`aaib_t005_2025`。

## 2. 首选补充：Malloy T150 的低油门接管

**事件：** 2023-06-27，英国 South Scarle。**来源：** AAIB Bulletin 10/2024，field investigation；网页发布于 2024-09-05。

**报告事实：** 无人机突破地理围栏后自动进入 RTL 并爬升。驾驶员把油门降至 2.6%，该输入在 RTL 下不起作用；随后经 LOITER 切回 STAB，低油门开始生效，飞机下降并滚转。后续全油门及滚转修正未能恢复，最终撞地。

**可用作研究动机的推论：** 模式改变会使已有输入获得新的控制含义；交接时的物理状态、此前输入状态与控制权接续需要一起看。该例适合说明为什么只测试每个模式的独立运行不足。

**不能据此声称：** 这是神经控制器记忆错误；事故只有切换一个原因；驾驶员输入历史等同于 GRU 状态。报告也讨论操作、推重比和恢复动作因素。

**复核入口：** [官方调查页](https://www.gov.uk/aaib-reports/aaib-investigation-to-malloy-aeronautics-t150-uas-registration-n-slash-a)；[PDF](https://assets.publishing.service.gov.uk/media/66d035d50b53069322597c7b/Malloy_Aeronautics_T150_10-24.pdf)。PDF p.3（Recorded information）、p.9（Analysis，RTL→LOITER→STAB 与 2.6% 油门）。引用键：`aaib_t150_2024`。

## 3. 无人机备选：Predator B 控制台交接

**事件：** 2006-04-25，美国 Nogales 附近。**来源：** NTSB 最终报告 CHI06MA121。

**报告事实：** 主控制台锁死后，驾驶员切至备用台，未按检查程序匹配控制杆位置。备用台 condition lever 处于切断燃油的位置，接管后燃油供应被关闭，发动机失去动力，飞机最终撞地。NTSB 将未执行交接检查程序列入事故原因，并指出训练监督和维护等因素。

**研究推论：** 控制源切换前的状态同步和输入语义值得专门测试。**限制：** 这是控制台交接，未涉及已证实的经典/神经控制器转换。

**复核入口：** [NTSB 最终报告](https://data.ntsb.gov/carol-repgen/api/Aviation/ReportMain/GenerateNewestReport/63577/pdf)，PDF pp.1–2（Analysis、Probable Cause）。引用键：`ntsb_predator_chi06ma121`。

## 4. 自动驾驶备选：Cruise 碰撞后响应选择

**事件：** 2023-10-02，美国旧金山。**来源：** Cruise 向 NHTSA 提交的 Part 573 召回报告 23E-086，提交日期 2023-11-07；这是制造商法定申报，不能标成 NTSB 独立调查。

**报告事实：** 另一车辆撞倒行人，使其进入 Cruise 路径。Cruise 制动但仍接触行人，碰撞被错误归为侧碰；系统随后选择靠边机动而非保持静止，将行人向前拖行。

**研究推论：** 本意降低风险的恢复行为，在不适合的物理条件下被选择也会增加危险；可引出模式进入条件的测试。**限制：** 这是行为/响应选择，不能说已确认经典与神经低层控制器进行了切换。

**复核入口：** [NHTSA 召回报告](https://static.nhtsa.gov/odi/rcl/2023/RCLRPT-23E086-7725.PDF)，pp.2–4（缺陷、风险、事件与修复）。引用键：`cruise_recall_23e086`。

## 5. 自动驾驶备选：Uber Tempe 的紧急响应窗口

**事件：** 2018-03-18，美国 Tempe。**来源：** NTSB 最终报告 HAR-19/03（2019），不是初步报告。

**报告事实：** 系统在碰撞前 1.2 秒识别紧急情况，随后按设计实施 1 秒 action suppression，抑制制动以等待重规划或操作者接管，启动时没有提醒操作者。操作者在碰前 0.02 秒转向接管，碰后 0.7 秒制动。事故同时涉及驾驶员分心及系统与组织安全因素。

**研究推论：** 后备接管者存在不等于接管有足够时间，控制衔接和安全功能协调也需要验证。**限制：** 自动系统→人的交接，不是经典→神经。报告中的重分类丢弃目标跟踪历史属于感知历史，不等同神经控制器记忆；不要用初报的 1.3 秒替换最终报告的 1.2 秒。

**复核入口：** [NTSB HAR-19/03](https://www.ntsb.gov/investigations/AccidentReports/Reports/HAR1903.pdf)，正文 pp.13–17（PDF pp.25–29），§1.5.5.3 与 Table 1。引用键：`ntsb_uber_har1903`。

## 6. 从事故连接到经典/神经混合架构

**文献：** J. Tanner Slagel 等，*A Verification Framework for Runtime Assurance of Autonomous UAS*，2024，NASA NTRS 20240007986，43rd Digital Avionics Systems Conference。

**材料支持的内容：** Simplex RTA 使用先进控制器和可信后备控制器，监测器发现相关条件后转移控制权；这是把 AI/ML 或其他未经充分验证的软件引入安全关键系统的一种架构。该研究形式化了 RTA 框架，并以无人机操作实例说明验证及采样时间要求。

**使用边界：** 这是一条“混合控制架构确实依赖切换”的文献证据，不是事故证据，也不证明本仓库的 V 或 fuzz 方法有效。论文明确不处理全部工业部署困难。先进控制器不必全是神经网络，可信后备也不能未经核查一概称为 PID。

**复核入口：** [NASA NTRS 条目与全文下载](https://ntrs.nasa.gov/citations/20240007986)，重点核对摘要中的 Simplex、advanced/reversionary controller 与 sampling requirements。引用键：`slagel_rta_uas_2024`。

## 7. 如何用于本项目引言

### 推荐论证链

1. **事实层：** 用 T005 说明模式激活后的失控与安全终止交互，用 T150 说明既有输入在切换后的危险作用。
2. **架构层：** 用 NASA RTA 文献说明 AI/ML 与可信控制器共存时，控制权切换是现实设计问题。
3. **研究问题层（本文推论）：** 将交接条件表示为物理状态、控制器历史、接管过程的组合，系统寻找危险条件。
4. **方法与证据层：** 用本仓库可复核的实验说明 V/覆盖反馈引导搜索的结果。事故本身不能证明 V 有优势，单个事故也不能支持失败率或通用因果结论。

### 可改写的中文引言草稿

真实无人机事故显示，进入新的控制模式时，既有输入状态、控制输出与安全处置机制之间的不匹配可能引发危险。Malloy T005 和 T150 的调查分别提供了自动模式激活及低油门模式交接的实例。另一方面，运行时保障架构通过在先进控制器和可信后备控制器之间转移控制权，支持将学习组件引入安全关键系统。由此，研究控制交接在不同物理状态、控制器历史及接管过程下的安全边界具有实际意义。本文关注通过测试和反例搜索发现这类危险条件。

上述文字是作者待改写的论证草稿：前两句对应事故资料，第三句对应架构文献，最后两句是本文研究定位。使用时引用 `aaib_t005_2025`、`aaib_t150_2024`、`slagel_rta_uas_2024`，不要把它作为调查报告原话。

### 三要素映射的边界

|素材|可启发的角度|不能替代的证据|
|---|---|---|
|T005|物理模型适配、控制输出、安全终止过程|神经控制器历史效应及经典→神经切换实证|
|T150|已有输入、飞行状态与模式接续的组合|GRU/previous-action 机制的因果证据|
|Predator B|接管前控制源同步、输入语义变化|自主软件控制器切换机制|
|Cruise|恢复行为进入条件与物理情境|低层经典/神经交接|
|Uber|紧急响应时序、后备接管和安全冗余|控制器隐藏状态效应|
|NASA RTA|混合控制与控制权转移的架构动机|本仓库测试方法的效率或安全保证|

## 8. 后续补充规则

- 投稿前再次打开来源，确认页码、版本与链接；事件日期和报告发布日期分开写。
- 对新闻线索优先追到原始调查或召回文件，区分机构结论、运营方调查和作者推论。
- 如后来发现真正涉及经典/神经控制交接的事故或工程报告，新增条目并独立核查，不把本库现有案例改称神经事故。
- 不将“尚未找到”写成“现实中不存在”；本库是定向素材搜集，不是穷尽检索。
