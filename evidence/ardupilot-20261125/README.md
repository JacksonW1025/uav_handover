# ArduPilot SITL 交接试验

ArduCopter 4.7.3 原生 ARM64 SITL、内建 Quad + 物理模型。七次独立仿真，固定学习器种子 20261123。保留 ArduPilot 的默认准入、GUIDED 内部控制链及保护。宿主侧切换经典与学习型外环，统一发送 MAVLink 世界坐标速度目标；没有启用机载自定义神经后端。与 Crazyflie 对照用相同结构的学习外环，速度尺度乘 3。任务从稳定北飞进入低速反向制动，正常落地。

## 观察到的飞行结果

- 快速进入时，两组入口北向真值速度都约 1.42 m/s。经典保持制动与换到学习外环相比，降到 0.15 m/s 从 907 ms 延长到 972 ms。慢速切换也有约 50 ms 的差异；快例更突出的读数是第一条输出几乎为零、第一秒末仍向前。
- 清零组首条制动从 −0.058 变为 −0.247 m/s，真值倾角峰值由 7.15° 变为 7.73°，最低前向速度由 −0.061 变为 −0.100 m/s，表现为制动更猛、略多向后超调。
- 旧参考与旧输出分别让机体第一秒多向前 21.1 cm 和 20.5 cm。两组均到约 320 ms 才首次采样到 `GUIP.vX` < −0.015 m/s。两类在机身表现相近，但从宿主的实际读入目标、候选输出和固件 GUIP 逐条对应可分辨发生点。

## 区分四类

- T1：`C_fast` 与 `N_fast`，新外环历史已暖、目标正确、指令已及时选入。观察需求较高时控制输出及制动裕量；`N_slow` 为温和对照。
- T2：`N_slow` 与 `H_clear`，只清零新外环记忆，观察首条指令、实际姿态和制动变化。
- T3：`R_stale` 在约 0.32 秒内把旧参考交给新外环，得到的正速度命令仍被飞控接收。
- T4：`D_hold` 新外环已读到正确制动参考并计算候选，却暂时继续选用上一经典命令。飞控记录可以核实收到的速度目标。本案异常位于宿主的指令交付，非电机级切换。

每组确认 MAVLink 结束时 ON_GROUND 且解除解锁，并以 DataFlash ARM 独立核实。无物理飞行。

## 与 PX4 结果如何对应

T1–T4 是机制映射，不是把这七次重复算成 PX4 样本。在本平台，C/N 是宿主外环，机载飞控仍执行原 GUIDED 路径；T1 观察到的是制动与距离余量差异，没有预设安全边界越界的证据。T2 是本实验外环记忆清空，不是机载 GRU 证据。T3 与 T4 用有意构造的仿真对照分离，不能解读为平台默认会自发选旧参考或延迟交付。T4 的观测边界是宿主输出选择和机载速度输入，不是电机实际样本交接。
