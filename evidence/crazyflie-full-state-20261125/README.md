# Crazyflie 补充记录：轻风对照与全状态飞控

这一批仍是 CrazySim/MuJoCo 的 cf2x_L250 软件在环。速度接口和全状态接口是两个独立的实验配置。实际倾角与目标倾角分开记录；停机后的倾斜不计入有效交接结果。

## 原速度接口：轻风对照

原厂 PID 内环和原宿主中止线不变。两组只在 X 轴外环来源上有差异。

| 0.5 m/s 固定风，同一转弯刹车 | 全经典 | 暖历史交接 |
|---|---:|---:|
| 入口倾角 | 4.56° | 4.61° |
| 标记后 1 s 内，原生估计倾角峰值 | 17.91° | 13.31° |
| +300 ms 原方向速度 vx | +0.039 m/s | +0.133 m/s |
| +400 ms 原方向速度 vx | −0.133 m/s | −0.004 m/s |
| 结果 | 正常落地 | 正常落地 |

这组数据再次观察到 T1 的制动减弱：侧向速度相近，但暖历史交接沿原方向继续飞得更久。倾角峰值低于经典组。

2.0 m/s 固定风的全经典组在标记后约 120 ms 触发 X 位置保护（X=1.709 m，倾角 4.80°），没有启动对应交接组。固件日志 +126.6 ms 首次显示停止后的零速度目标。随后下降过程中，估计倾角在 +365.7 ms 首次超过 45°（47.47°），+446.6 ms 达到 63.68°。该组没有切换，超过 45° 发生于停止后，也没有实际四路 PWM 记录。

## 独立全状态接口：原厂 Mellinger

全状态配置在起飞前选定原厂 Mellinger。平滑制动两臂使用同一内环、相同位置与加速度参考，改变 X 速度命令的来源，并记录 MuJoCo 真值和模拟器接收的四路 PWM。原速度实验未改。

| 案例 | 标记后 1 s 内、仍有电机输出时的真值峰值 | 经过 |
|---|---:|---|
| 原厂全状态低幅度资格检查 | 2.72° | 起飞、平移、正常落地。 |
| 平滑制动，全经典 | 39.53°（+261.8 ms） | 正常落地。 |
| 平滑制动，暖历史交接 | 34.69°（+236.7 ms） | 正常落地。 |
| 较急制动，全经典 | 52.58°（+268.5 ms） | +215.6 ms 首次真值超过 45°；之后触发本配置宿主停止保护，相应交接臂未启动。 |

较急制动的 52.58° 发生在停止前，峰值附近模拟器收到的四路 PWM 是 33535、65535、65535、33535；首个零 PWM 包在 +284.2 ms。保护报告的 55.65° 是固件估计值，不是 MuJoCo 真值峰值。这个结果只说明全经典的较急制动也可以超过 45°。另一次脚本初始化失败未发出正式轨迹，未计入表中。

## T2 回放与当前边界

[t2-offline-replay.csv](t2-offline-replay.csv) 固定平滑制动交接的已记录状态与参考，只把入口历史清零一次，再复算接下来七拍。清零使首拍 X 命令从 +0.456 变为 +0.331 m/s；+120 ms 附近，暖历史仍给 +0.078 m/s，清零回放已给 −0.013 m/s。这是反事实命令比较，没有新闭环数据或反事实倾角。此次没有启动新的 T3 闭环试验。**目前没有同场景“全经典低于 45°、交接高于 45°”的测量。**

## 复核

- [案例索引](case-index.json)记录标记时间、启动结果与 CSV 行数；[实测摘要](metrics.json)记录峰值和终止顺序。公开 CSV 仅含标记附近窗口及核对结束的末端样本。
- CSV 的 wall 为宿主 monotonic 时间，sim_s 为模拟器时间。不同启动的绝对时间不直接作差。
- motor.m*req 在当前 SITL 中绑定没有更新的实机电池补偿缓冲，飞行期间也可能一直为零，不能证明停桨。本目录全状态组的 motor-pwm.csv 是模拟器收到的 CRTP 电机包；plant.csv 另含模拟器转子转速和姿态。原速度组没有这项证明。
- 从仓库根目录运行 `python3 evidence/crazyflie-full-state-20261125/verify.py`，可核对窗口哈希、实际倾角、PWM 与停止的先后及 T2 表内部一致性。脚本不启动仿真；T2 清零分支数值是保存的反事实输出，校验脚本不重新训练学习器。
