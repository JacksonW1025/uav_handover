# Crazyflie T1：转弯中接管，原方向刹得更慢

同一二维轨迹分别运行全经典与暖历史交接。外部学习器只接管 X 轴，Y 轴跟踪与 Z 轴控高保持一致；Crazyflie 固件 PID 内环不变。两组均未注入延迟或断流，且都正常落地。姿态和速度取自 Crazyflie 固件估计。

| 观测 | 全经典 | 暖历史交接 |
|---|---:|---:|
| 入口速度 (X, Y) | (0.428, 0.229) m/s | (0.427, 0.231) m/s |
| 入口倾角 | 4.65° | 4.52° |
| +300 ms X 速度（仍向原方向） | +0.030 m/s | +0.126 m/s |
| +300 ms Y 速度 | +0.312 m/s | +0.310 m/s |
| +300 ms 运动方向偏离 +Y | 5.42° | 22.09° |
| +400 ms X 速度 | −0.149 m/s | −0.013 m/s |
| 前 1 秒倾角峰值 | 17.16° | 12.11° |
| 前 1 秒最大 X 前移 | 8.67 cm | 9.58 cm |

两组在 +300 ms 的任务 X 反向速度均为 −0.19 m/s。经典组已几乎刹住原方向运动，交接组同时还在向前和侧向移动。+400 ms 时，经典组已明显反向，交接组才刚反向。这个案例的差异是**刹车响应较弱**，不是倾角升高。

首条发送的 X/Y 组合在固件目标日志中分别于 +14.31 ms / +15.27 ms 观察到。以宿主标记切换拍为零点（全经典用同一轨迹相位）；运动量由宿主回调时间前后的原生位置样本线性插值得到。固件目标日志包含采样与回传，不能用来精确计量电机执行延迟。

离线复算交接同一状态：在 +300 ms，经典外环计算 −0.279 m/s，其训练教师为 −0.141 m/s，学习器实际选中 −0.139 m/s。本案例这一时刻的较弱制动主要随接手控制规律而来，并非神经网络拟合误差所致。三项均由 +280/+320 ms 宿主控制拍的值插值；与独立经典飞行的实际发出命令不是同一测量。
