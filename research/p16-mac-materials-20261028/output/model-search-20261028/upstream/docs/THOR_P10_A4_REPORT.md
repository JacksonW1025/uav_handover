# P10-A4：轻量代理与 Lyapunov 决策可行性实验

最终入口：本报告及 [机器结论](../data/p10-20261025-a4/conclusion.json)。A/A2/A3 原文件和 NOT_PASSED 保留。本轮选择路线 **B**，实际系统理论关卡仍为 **NOT_PASSED**。新增 SITL／开发飞行／正式飞行／实机飞行均 **0**；条件性诊断预算使用 0/12；B/C/D、A5 均未启动。

1. **模型哪里有效、哪里失效？** M0 在已见开发数据、已知未来目标的回放中可作局部响应比较：4 个检查航次的 16 个捕获／接回窗口，峰值倾角代理误差平均 1.189°、最大 3.638°。它把 4 ms 控制观察周期误当成每次都有新位置观测；实际位置样本按 0／8 ms 交替推进。修正时钟改善一步误差，却未改善完整回放；增加加速度状态的 M2 在长回放中明显失效。上述 16 窗口实测均未超过 45°，不能据 false_low=0 推断漏报率。
2. **旧误差要求为何不相容？** A3 的旧 q 必要条件 7,196/7,196 次违反，原结果逐字节复现。A4 用双轴、相同步长、坐标、单位及保留交叉项的完整公共 P 度量，找到记录要求统一半径至少 3.240511006595714。最大已完成精确审计的条件半径是 0.001，不能称其为最大可容忍半径。更强的有理数反例说明：包含任意逐步物理误差的完整半径 ≥3 球，在当前 M0 启动的前 88 ms 已含倾角代理越限序列。这说明该无结构接口过宽，不证明真实系统必败或所有 Lyapunov 方法不可能。
3. **捕获后限幅能否处理？** 能在声明的代理内处理。分段 clip 余项覆盖可达集合跨界的所有模式；原 T0 零模型误差证书完整通过，经历 170 个饱和轴样本。CR06 条件证书经历 752 个饱和轴样本及一次跨界余项组。代价是时变集合／储能计算与严格误差前提，不能沿用旧无饱和收缩率。当前构造未证明渐近稳定。
4. **Lyapunov 是否改变具体决定？** 有条件地改变代理准入：ε=0.001 时单点回放接受 T0 和 C04，集合构造对 T0 为 UNKNOWN，C04 则通过整段精确集合审计。另推导首次瞬时速度不裁剪的充分约束 α≥0.454711853965；这不是连续 α 修复族的整段保证。不能据这些结果跳过真实安全测试，没有证明减少评价次数。
5. **路线是否继续？** 停止继续扩建当前“每步任意误差球”证书。保留源码参考／观测映射、回放与限幅集合审计工具。如果另获授权，先构建位置观测保持、时钟与有色误差的共同接口，证明其非空、可检查及传播关系，再决定是否开展最小诊断；本轮不自动开启 A5。

## 模型、坐标与时钟核查

P9 用 20 ms 数据拟合 kp/kv、τ=0.08 s、delay=0.088 s，原预测 8 ms／11 槽；A3 改为 4 ms／22 槽及 q 指数响应加 p/v 梯形积分。两者不是严格重采样，增益无需必然保持。M0 原样保留这项假设。FIFO 是代理实现的确定性历史，native 无同名 FIFO；初始化沿用 A3 源侧启动观测最早可用样本填充，再从同一起点完整暖机，不先造运动历史。

公共输出为 NED p、v 和 `q=-g*body_z_xy/body_z_z`（Rzz>0.1）；P 度量在固定初始目标 yaw 的水平 FLU 基底中计算。q 是姿态几何代理，具有 m/s² 单位，不等于已证明的净水平加速度：推重比、垂直加速度、气动力、姿态／估计器动态均影响这种等同。M0 固定 yaw；M1 处理延迟目标坐标历史和命名样本时钟。单轴 P47 以双轴块组合，p/v/q 交叉项均保留，没有用单个 q 最大值冒充完整扰动范数。

8 航次的 research_timing 序列全为 4 ms；命名 LP 样本推进 0 或 8 ms、年龄 0/4/8 ms，姿态样本推进 0/4/8 ms、年龄 0/4 ms。位置残差有明显交替结构，NED x 分量 lag-1 相关约 −0.906 至 −0.966。固定参数仅改观测时钟的诊断使逐航次 P95 从 1.086–1.581 降为 0.209–0.564。这是时序对照证据，不能据此把其余误差因果归为 GRU 或推力。

RREC=2 的 dev03/04 若用旧 p6 重建，会出现 10,086／10,020 个目标分量不匹配；改用已有 p7 真实恢复目标重建后，全部 8 航次网络输入检查均为 0 个不匹配（阈值 1e-4）。这属于 A 类重建问题，原诊断保留。B 类为步长和参数重用；C 类为上述未建模动态；D 类为缺少独立激励、前瞻样本及硬误差／实际采样间观测。M2 闭环回归 q 系数贴近下界也属于可辨识性限制，不能解释为 q 对加速度无影响。
