|---|---|---|---|---|
|倾角|11 / 21 / 0|1/11|2/21|0/32|

三值规则：有效前缀有失败见证判FAIL；完整覆盖且无失败才SUCCESS；无失败但截断的高度记UNKNOWN。模型本轮没有主动放弃判断，因此高度漏判不能通过UNKNOWN藏起来。任务OR正确不提供高度分项保证。
